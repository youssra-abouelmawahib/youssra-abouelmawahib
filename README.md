## Projects

### 🔁 Transformer-Based Sequential Recommendation — *in progress*
Implementing SASRec and BERT4Rec in PyTorch for next-item prediction on MovieLens-1M, compared with GRU4Rec and popularity baselines (HR@10, NDCG@10).

`PyTorch` `Transformers` `Recommender Systems`

### 🔬 VISAtlas — Research Paper Reproduction
Reproduced **VISAtlas**, a system that uses neural image embeddings to search large visualization collections.
- Ran and debugged the authors' implementation, then tested it on new image inputs.
- Studied how CNN embeddings, cross-entropy and triplet loss shape similarity retrieval.
- Analyzed practical limitations and how the experiments support the paper's conclusions.

`Python` `CNN Embeddings` `Representation Learning`
